# US-018 Slovenian and English user interface

> For: agent (reads), human (reviews) · Owner: Product owner · Agent: read-only

## Story

As a user, I want to use the product in Slovenian or English and switch between them, so that I understand every text in my own language.

## Purpose

The customer text is Slovenian, but the team may not be. Without the switch half of the users would work in a language they do not read well. Priority and MVP confirmed by the developer: the interview gives the decision but no priority.

## Definitions

| Term | Meaning |
|---|---|
| Active language | The language of the UI, Slovenian by default. |

## Rules

| ID | Rule (EARS) | Source |
|---|---|---|
| R-018-01 | The system shall show the whole UI in Slovenian by default and in English on choice. | Q-11 |
| R-018-02 | When the user chooses a language in the switch in the header, the system shall show all texts in that language at once, without losing the user's unsaved input. | Q-11 |
| R-018-03 | The system shall remember the user's choice in the browser for the next visit. Per browser, not per account (confirmed by the developer). | Q-11 |
| R-018-04 | While Slovenian is active, the system shall show dates as d. M. yyyy, times as HH:mm, decimals with a comma, and the UI in the formal "vi"; while English is active, dates as yyyy-MM-dd and times as HH:mm. | Q-11a, Q-34a |
| R-018-05 | The system shall show times in the project time zone in both languages. | Q-26 |
| R-018-06 | The system shall show country names in the active language. | Q-11 |
| R-018-07 | The system shall sort and search by Slovenian rules in both languages. | Q-11a |
| R-018-08 | The system shall keep contact data, tags, keys and values unchanged when the language changes. | Q-11 |

## Acceptance criteria

| ID | Given | When | Then | Rules |
|---|---|---|---|---|
| AC-018-01 | A first visit | The sign-in screen opens | It is in Slovenian | R-018-01 |
| AC-018-02 | The user is on the contact form with unsaved text | The user switches to English | All labels are English; the typed text is still there | R-018-02 |
| AC-018-03 | English was chosen | The user comes back later in the same browser | The UI is English | R-018-03 |
| AC-018-04 | An entry at 2026-07-01T22:30:00Z | Shown in Slovenian; in English | `2. 7. 2026 00:30`; `2026-07-02 00:30` | R-018-04, R-018-05 |
| AC-018-05 | Slovenia as a country | Shown in each language | "Slovenija"; "Slovenia" | R-018-06 |
| AC-018-06 | Contacts Čuk, Cerar, Sever, Šuster | Sorted in English UI | The same order as in Slovenian UI | R-018-07 |
| AC-018-07 | Ana's tags and attributes | The language changes | They are unchanged | R-018-08 |

## Edge cases

| ID | Input or situation | Expected result | Rules |
|---|---|---|---|
| EX-018-01 | The browser language is French | Slovenian | R-018-01 |
| EX-018-02 | An error message from the server | Shown in the active language | R-018-01 |
| EX-018-03 | Winter time (2026-01-15T22:30:00Z) | Shown as 23:30 | R-018-05 |
| EX-018-04 | A text missing in a language file | The build or check fails; the UI never shows a key | R-018-01 |

## Out of scope

Other languages; translating contact data; a language per account; right-to-left text.
