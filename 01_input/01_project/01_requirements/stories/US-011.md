# US-011 Select contacts and export to Excel

> For: agent (reads), human (reviews) · Owner: Product owner · Agent: read-only

## Story

As an Owner or Editor, I want to tick contacts and export them to an Excel file, so that I can use them in other tools, for example a mailing tool.

## Purpose

The customer's other tools work from Excel. This is the only way contact data leaves the product, so it must be exact, safe and traceable.

## Definitions

| Term | Meaning |
|---|---|
| Selection | The contacts ticked in the list, including "select all N results". |
| Export | An `.xlsx` file with one row per ticked contact. |

## Rules

| ID | Rule (EARS) | Source |
|---|---|---|
| R-011-01 | While an Owner or Editor views the list, the system shall show a tick box per row, "select all on this page" and "select all N results of the current filter". | Q-23b |
| R-011-02 | While the user pages or sorts, the system shall keep the selection; when the search text or the filter changes, the system shall clear the selection. A change of search text counts as a change of filter (confirmed by the developer). | Q-23b |
| R-011-03 | While no contact is ticked, the system shall show the Export button disabled. | Q-24 |
| R-011-04 | When an Owner or Editor exports, the system shall write one sheet with a header row and one row per ticked contact, in the order of the current list sort, and no contact of another group. | Q-24, Q-24a |
| R-011-05 | The system shall write the columns: the 11 predefined fields, a Tags column (tag names separated by commas), then one column per attribute key used in the selection (keys compared ignoring case, in alphabetical order); headers use the UI names in the active language, country names the active language. Column order of keys confirmed by the developer. | Q-24, Q-11 |
| R-011-06 | The system shall name the file `<group name>_<YYYY-MM-DD>.xlsx` with the date in the project time zone, and replace characters not allowed in file names with "_" (confirmed by the developer). | Q-24a |
| R-011-07 | The system shall write the header bold and frozen, and e-mail and phone cells as text. | Q-24a |
| R-011-08 | If a cell value starts with `=`, `+`, `-` or `@`, then the system shall write it as plain text, never as a formula. | Q-24a |
| R-011-09 | If more than 10,000 contacts are ticked, then the system shall refuse the export, create no file and ask the user to narrow the selection. | Q-24a |
| R-011-10 | While the user is a Viewer, the system shall show no tick box and no Export button and shall refuse an export request (BR-02). | Q-06b |
| R-011-11 | The system shall write the file in UTF-8 so that č, š, ž and other characters show correctly in Excel. | Q-11a |
| R-011-12 | The system shall not export contacts in Trash. | Q-23b |

## Acceptance criteria

| ID | Given | When | Then | Rules |
|---|---|---|---|---|
| AC-011-01 | The Editor has filtered 2 contacts (E2E journey J3) | She chooses "select all 2 results" and "Export" | A file `Konferenca 2026_2026-11-09.xlsx` (on 2026-11-09) is downloaded with a header and 2 rows | R-011-01, R-011-04, R-011-06 |
| AC-011-02 | Ana has `kompetenca=spletnoProgramiranje` and tag `udelezenec2025`; another contact has neither | Both are exported | The columns are the 11 fields, Tags, `kompetenca`; Ana's row has `udelezenec2025` and the value; the other has empty cells | R-011-05 |
| AC-011-03 | A contact has tags `a`, `b` | Exported | The Tags cell is `a, b` | R-011-05 |
| AC-011-04 | The language is English | Exported | Headers are the English UI names | R-011-05 |
| AC-011-05 | Nothing is ticked | The list is shown | Export is disabled | R-011-03 |
| AC-011-06 | 60 contacts, 25 per page | The user ticks 3 on page 1, goes to page 2 and ticks 2 | The selection shows 5; export has 5 rows | R-011-02, R-011-04 |
| AC-011-07 | 5 contacts are ticked | The user adds a filter | The selection is cleared | R-011-02 |
| AC-011-08 | A contact has notes `=HYPERLINK("http://x")`, company `+evil`, job title `-1`, city `@x` | Exported | Each cell contains the text unchanged and is not a formula | R-011-08 |
| AC-011-09 | 10,001 contacts are ticked with "select all" | The user exports | Refused with a message; no file | R-011-09 |
| AC-011-10 | Petra is a Viewer | She looks at the list; an export request is sent through the API | No tick box and no Export; the request is refused (403) | R-011-10 |
| AC-011-11 | Contact Ana has e-mail `ana.novak@example.com` and phone `+386 41 555 123` | Exported and opened in Excel | E-mail and phone are text; `+386 41 555 123` is not turned into a number; "č" shows correctly | R-011-07, R-011-11 |
| AC-011-12 | Contact in Trash | A "select all" export is made | The trashed contact is not in the file | R-011-12 |
| AC-011-13 | The header row of an export | The file is opened | The header is bold and stays visible when scrolling | R-011-07 |

## Edge cases

| ID | Input or situation | Expected result | Rules |
|---|---|---|---|
| EX-011-01 | Exactly 10,000 ticked; 10,001 | Exported; refused | R-011-09 |
| EX-011-02 | Group name `A/B:C` | File name `A_B_C_<date>.xlsx` | R-011-06 |
| EX-011-03 | Keys `Kompetenca` and `kompetenca` in two selected contacts | One column | R-011-05 |
| EX-011-04 | No contact in the selection has attributes | No attribute columns | R-011-05 |
| EX-011-05 | Export at 23:30 UTC | The date is the date in Europe/Ljubljana | R-011-06 |
| EX-011-06 | A value starting with a tab or `=` after spaces | Cell value written as given; only the four listed starting characters are neutralised | R-011-08 |
| EX-011-07 | Contact has empty fields | Cells are empty | R-011-04 |
| EX-011-08 | Selection of a contact that was meanwhile trashed by someone else | The export leaves it out | R-011-12 |

## Out of scope

Export to CSV; import from Excel; History export; templates; other bulk actions on several contacts; scheduled exports. The export is written in the History (US-013).
