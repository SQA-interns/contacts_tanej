# US-002 Create a group and list my groups

> For: agent (reads), human (reviews) · Owner: Product owner · Agent: read-only

## Story

As a signed-in user, I want to create a group with a name and see the groups I belong to, so that I can keep the contacts of one project or company together and apart from all others.

## Purpose

The group is the unit of isolation and sharing. Without it contacts of different projects mix and nobody can work together on one contact list.

## Definitions

| Term | Meaning |
|---|---|
| Groups list | The screen listing every group of which the user is a member, with the user's role. |

## Rules

| ID | Rule (EARS) | Source |
|---|---|---|
| R-002-01 | When a user with a verified e-mail creates a group with a valid name, the system shall create the group, make the user its Owner and open the (empty) group. | Q-05, Q-02b |
| R-002-02 | If the group name is empty after trimming spaces, or longer than 100 characters, then the system shall refuse and store nothing. Only the name is needed (Q-02); the 100-character limit is confirmed by the developer. | Q-02 |
| R-002-03 | If creating, renaming or restoring a group (R-002-08, US-015) would give any Owner of that group two groups not in Trash with the same name ignoring case (after trimming), then the system shall refuse, change nothing and show the reason. The system shall allow the same name for groups with different Owners and shall ignore groups in Trash. Promoting a member to Owner (US-003, US-004) is never refused because of a name; a same-name pair that arises that way is accepted. Developer answer. | Q-02 |
| R-002-04 | The system shall show every user, in the groups list, exactly the groups of which the user is a member and which are not in Trash, each with the user's role; it shall show no other group (BR-01). | Q-02b, Q-13 |
| R-002-05 | The system shall not limit the number of groups a user creates or belongs to. | Q-30 |
| R-002-06 | When a user opens a group, the system shall show that group's contacts and no contact of another group. | Q-02b, Q-13 |
| R-002-07 | If a user who is not a member of a group asks for it by its address, then the system shall answer "not found" and show nothing of the group. | Q-12 |
| R-002-08 | When an Owner gives the group a new valid name, the system shall rename the group; the name rules of R-002-02 and R-002-03 apply (checked for every Owner of the group), the group itself not counting as a clash with its own name (a change of capitalisation only is allowed). If the name is not valid or clashes, then the system shall refuse and change nothing. The system shall append a group-level History entry with the old and new name (US-013). If the member is an Editor or Viewer, then the system shall refuse (403). Developer answer. | Q-02 |

## Edge cases

| ID | Input or situation | Expected result | Rules |
|---|---|---|---|
| EX-002-01 | Name of exactly 100 characters | Accepted | R-002-02 |
| EX-002-02 | Name of 101 characters | Refused; nothing stored | R-002-02 |
| EX-002-03 | Name `Čebelarji & Co` with accents and symbols | Accepted and shown unchanged | R-002-01 |
| EX-002-04 | User with an unverified e-mail tries to create a group | Refused; see US-001 | R-002-01 |
| EX-002-05 | A group is in Trash (US-015) | It does not appear in any member's groups list | R-002-04 |

## Out of scope

A group description or logo; changing the creator; a limit on groups; joining a group (US-003); deleting a group (US-015).
